# Assessing metadata privacy in neuroimaging

**Status:** published. **Maintainer/contact:** Cyril Pernet ([@CPernet](https://github.com/CPernet)).

Kibsgaard, E., Sue Jwa, A., Markiewicz, C. J., Rodriguez Gonzalez, D., Sainz Pardo, J., Poldrack, R. A., & Pernet, C. R. (2026). *Assessing metadata privacy in neuroimaging*. Imaging Neuroscience, 4, IMAG.a.1144. https://doi.org/10.1162/IMAG.a.1144

## Analysis and software

- **Authoritative analysis repository:** https://github.com/CPernet/OpenNeuro_MetaPrivAssessment
- **Tool repository:** https://github.com/CPernet/metaprivBIDS
- **Paper:** https://doi.org/10.1162/IMAG.a.1144

The analyses examine privacy in metadata accompanying OpenNeuro datasets using metaprivBIDS. Notebooks, supporting material and execution details remain in the analysis repository. This folder is a discovery entry, not a duplicate analysis or software distribution. Consult the linked repositories for data provenance, access conditions, dependencies and licensing.
